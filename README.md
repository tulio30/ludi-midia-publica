# LUDI — mídia pública

Imagens de posts já aprovados do `@educa_ludi`, hospedadas aqui porque a API do Instagram exige
uma URL pública para publicar (ela não aceita upload de arquivo).

**Não coloque nada privado aqui.** Só entra imagem de post que já passou pelo guardião e foi aprovada
pelo Túlio. Quem envia é `automacao/hospedagem.py`, do repositório de marketing.

O nome de cada arquivo são os 16 primeiros caracteres do SHA-1 do conteúdo, para o envio ser idempotente.
